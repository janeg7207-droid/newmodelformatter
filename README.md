0.15 decodes supported older 2K24 inline-v1 material libraries and generates
native material tables and JMTLs through the existing Gorilla writer. This
addresses the missing-material path associated with invisible direct ports.
Known source identities, bounded typed records and texture references are checked.
The existing eye settings, guarded teeth/mouthbag repair, CakeView, folder input/output
and YCL workflow remain. Originals stay preserved.

493 tests and seven exact-candidate native folder checks passed. Full source-ZIP
rebuilding reproduces the tested EXE exactly. These checks do not establish
in-game visibility, tooth brightness or a universal skin/clipping fix.
Flip's reported elbow-pad skin overlap remains under investigation.
Direct 2K22/2K23 conversion is still unsupported in 0.15.
