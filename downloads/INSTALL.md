# Installation

See [NEW_FORMATTER.md](NEW_FORMATTER.md) for current 0.14.1 installation,
verification and remaining limitations. See [SOURCE_REBUILD.md](SOURCE_REBUILD.md)
for rebuilding the EXE from the exact original supplied Gorilla EXE.

For integration into a COPY of a complete recovered Gorilla source project,
run `apply_source_patch.py --help`. It installs the runtime repair helpers and
retains a backup of the original GUI. Preserve the original source.
