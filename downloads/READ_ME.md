# Experimental NewModelFormatter download

Download `NewModelFormatter_0.3_patch_installer.zip`, extract it, and double-click
`Install.cmd`. Choose your original **Gorilla Model Formatter.exe** from
Gorilla Model Formatter 1.0. The installer creates a separate
`NewModelFormatter.exe` beside the installer files.

The patch reconstructs the inspected experimental EXE byte for byte and checks
source/output SHA-256. It preserves the original EXE, input/output formats,
folder workflow, and CakeView selection/checks.

21 regression tests and Wine startup/native model/material diagnostics passed.
The Windows PowerShell installer itself has not been run in this Linux workspace.
Billie's material case mismatch is repaired in actual file checks; her physics
repair is still under investigation. Rey's optional gear profile and skin hiding
need entrance/gameplay tests. No blood, belt, or teeth repair is claimed.

The archive contains installation instructions and the recorded validation limits.
It does not contain the original Gorilla EXE or any original mod assets.
